# API reference

Interactive docs: <http://localhost:8000/docs> (Swagger UI generated by FastAPI).

Admin endpoints (marked 🔒) are open when `ADMIN_TOKEN` is unset; otherwise send `X-Admin-Token: <token>`.

## Bookings

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/bookings` | Create a booking. Body: `patient_name`, `phone`, `pickup_lat`, `pickup_lon`, `hospital_id`, optional `notes`, `auto_assign` (default true). 422 if the hospital is unknown or pickup is outside the service area. |
| GET | `/api/bookings` | Recent bookings (`?limit=50&active_only=false`). |
| GET | `/api/bookings/{id}` | Booking with live journey state (`live`: ambulance, remaining route, ETA). |
| POST | `/api/bookings/{id}/assign` | Assign now (optionally `{"ambulance_id": "A2"}`); 409 if none free. |
| POST | `/api/bookings/{id}/cancel` | Cancel; releases priority and sends the ambulance home. |
| GET | `/api/bookings/{id}/route` | Stored route legs (GeoJSON) + remaining route + ETA. |
| GET | `/api/bookings/{id}/events` | Journey and signal event history. |

Booking statuses: `WAITING_FOR_AMBULANCE`, `EN_ROUTE_TO_PICKUP`, `AT_PICKUP`, `TRANSPORTING`, `COMPLETED`, `CANCELLED`, `FAILED`, `REJECTED`.

## Network, fleet, intersections

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Liveness. |
| GET | `/api/network` | Roads (GeoJSON), intersections with phase groups, hospitals, bases, bbox. |
| GET | `/api/hospitals` | Hospitals. |
| GET | `/api/ambulances` | Ambulances with status and position. |
| GET | `/api/intersections` | All signals with current state and queues. |
| GET | `/api/intersections/{id}/status` | Signal state, queue history, priority sessions, active/recent recoveries. |
| GET | `/api/intersections/{id}/events` | Stored signal events for the current run. |
| GET | `/api/intersections/{id}/snapshots` | Stored traffic snapshots (every 10 s simulated). |
| POST 🔒 | `/api/intersections/{id}/priority` | Operator trigger on a simulated signal: `{"approach": "<edge id>", "action": "request"|"release", "hold_s": 45}`. Same safe transition as ambulance priority; recovery follows the release. |
| POST 🔒 | `/api/intersections/{id}/test-ambulance` | Send a simulated ambulance through this junction (`{"approach": optional, "upstream_m": 800}`): full route-aware request → green → release → recovery. |

## Real maps (OpenStreetMap)

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/map/areas` | Presets and cached areas, the current map, loader status. |
| GET | `/api/map/status` | Loader state (`idle`, `queued`, `downloading`, `building`, `ready`, `error`) and message. |
| GET | `/api/map/search?q=Kharghar` | Place search (Nominatim) → names with bounding boxes. |
| POST 🔒 | `/api/map/load` | `{"area": "navi-mumbai"}` or `{"bbox": [south, west, north, east], "name": "...", "detail": "auto|full|main", "refresh": false}` or `{"area": "demo"}`. Downloads from Overpass in the background, builds the network and switches the live simulation to it (`network_version` in the WebSocket increments; the dashboard reloads `/api/network`). Max 900 km². |
| POST 🔒 | `/api/map/upload` | Multipart `file` (.osm XML export or Overpass .json, optionally .gz), `name`, `detail` – same, without the Overpass API. |

## Simulation

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/simulation/status` | Run parameters, time, vehicle count, safety violations. |
| GET | `/api/simulation/snapshot` | Full snapshot (`?vehicles=false` to skip vehicles). The WebSocket sends a compact form: `vehicles_q = {"o": [lat0, lon0], "d": [dlat·1e5, dlon·1e5, speed·10, is_ambulance, …]}` and signals without static phase groups. |
| POST 🔒 | `/api/simulation/control` | `{"action": "pause"|"resume"|"reset", "speed": 5, "demand": "low|medium|high|peak", "priority_enabled": false, "recovery_enabled": true, "queue_source": "cv", "seed": 7, "engine": "sumo", "auto_emergencies_per_hour": 30}`. Changing demand, seed, engine or recovery starts a new run. Demand is scaled to the size of the map (`demand_scale`, `vehicles_per_hour` in the status). |
| GET | `/api/events` | Recent in-memory events. |

## Analytics, experiments, computer vision

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/analytics/summary` | Aggregates over stored journeys (baseline vs priority), recoveries, event counts. |
| GET | `/api/analytics/{booking_id}` | Journey metrics, priority events and recoveries for one booking. |
| POST 🔒 | `/api/experiments` | Start a matched experiment: `{"demands": ["low","medium","high"], "seeds": [1,2,3,4,5], "engine": "builtin"}` → 202 with id. |
| GET | `/api/experiments`, `/api/experiments/{id}` | Progress and results (summary + per-trial rows; also saved to `results/`). |
| GET | `/api/cv/{node}/estimate` | CV estimate vs ground truth for every approach of a junction. |
| GET | `/api/cv/{node}/frame.png?approach=EDGE&truth=true` | Annotated camera frame. |
| POST 🔒 | `/api/cv/evaluate?seconds=300&demand=medium` | Precision/recall/count & queue error on simulated frames. |

## Video analytics

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/video/capabilities` | Which detectors are available (YOLO, OpenCV DNN, motion) and bundled samples. |
| POST 🔒 | `/api/video/upload` | Multipart upload: `file`, `mode` (`live`/`batch`), `detector` (`auto`/`yolo`/`opencv-dnn`/`motion`), `conf`, `target_fps`, `loop`, `name`. |
| POST 🔒 | `/api/video/sources` | `{"kind": "url", "uri": "rtsp://…"}`, `{"kind": "webcam", "uri": "0"}`, `{"kind": "file", "uri": "<sample name>"}` or `{"kind": "push"}`; optional `detector`, `conf`, `target_fps`, `classes`, `detect` (`vehicles` \| `road` \| `all`), `imgsz` (detector input px), `target_fps`, `zone`, `attach: {node, approach}` (simulated junction) or `{field, approach}` (real-time signal), `ambulance: {enabled, use_model, use_beacon, use_livery}`. |
| GET | `/api/video/sources`, `/api/video/sources/{id}` | Status, live stats, per-class totals, alerts, timeline, summary, output files. |
| PATCH 🔒 | `/api/video/sources/{id}` | `zone: {roi: [[x,y]…], line: [[x,y],[x,y]], meters_per_pixel}` (fractions 0–1), `attach`, `clear_attach`, `conf`, `classes`. |
| POST 🔒 | `/api/video/sources/{id}/stop` · DELETE 🔒 `/api/video/sources/{id}` | Stop / remove. |
| GET | `/api/video/sources/{id}/stream.mjpg` | Annotated live video (Motion-JPEG; works in `<img>` and VLC). |
| GET | `/api/video/sources/{id}/frame.jpg` | Latest annotated frame. |
| GET | `/api/video/sources/{id}/files/{name}` | Batch outputs: annotated video (WebM/MP4), `frames.csv`, `timeline.csv`, `summary.json`. |

## Real-time signals (field junctions)

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/field` | All junctions (states, mode, active/pending priority, events, driver and source status), GPS ambulances. |
| POST 🔒 | `/api/field/junctions` | Create or update: `{id?, name, lat, lon, approaches: [{id, name, bearing, lanes}], groups?, plan?, mode: control/mirror, driver: {type: virtual/serial/http/mqtt, …}, source: {type: none/spat/sensorthings/json/mqtt, …}, corridor?}`. |
| DELETE 🔒 | `/api/field/junctions/{id}` | Remove. |
| POST 🔒 | `/api/field/junctions/{id}/priority` · `/release` | Operator override `{approach}` / release. |
| GET | `/api/field/junctions/{id}/spat` · `/state` | Open-format outputs: J2735-style SPaT JSON, simple JSON. |
| POST 🔒 | `/api/field/sources/test` | Poll a live source config once. |
| GET | `/api/field/serial-ports` | Serial ports for the Arduino driver. |
| POST | `/api/field/ambulances/{id}/position` | GPS fix `{lat, lon, speed?, heading?}` → corridor logic; returns distance/approach/ETA per junction. |
| POST 🔒 · DELETE 🔒 | `/api/field/ambulances/{id}/simulate` | Simulated drive `{junctions: [...], entry_approach?, speed_kmh}` or `{path: [[lat, lon], …]}` / stop. |
| POST 🔒 | `/api/field/follow-sim` | `{enabled}` – feed simulated-city ambulances to real-time junctions. |
| GET | `/api/video/webcams` | Cameras on the backend machine that deliver frames. |
| POST 🔒 | `/api/video/photos` | Multipart `files` (1–100 images) + `detector`, `conf`, `detect`, `ambulance`, `imgsz` (default 960) → batch with per-photo objects, vehicles by class, occupancy, congestion, ambulance check, annotated images, `results.csv`/`results.json`. `POST /api/video/photos/sample` uses the bundled photo. |
| GET | `/api/video/photos`, `/api/video/photos/{id}`, `/api/video/photos/{id}/files/{name}` | List batches, one batch, annotated/original images and CSV/JSON. `DELETE /api/video/photos/{id}` removes one. |
| GET | `/api/video/selftest?detector=auto` | Runs the detector on a bundled street photo: `{"ok", "detector", "ms", "detections": [{"cls", "conf"}]}` – quick check that object detection works. |

## WebSockets

| Path | Messages |
|---|---|
| `/ws/simulation` | Every 0.5 s: `{type: "simulation", t, signals, ambulances (with remaining routes), vehicles [[lat, lon, speed, isAmbulance]], priority, recovery, journeys, events, safety_violations, …}` |
| `/ws/field` | Every 0.5 s: real-time junction states, priority, events, GPS ambulances. |
| `/ws/video/{id}` | Every 0.5 s: source status, live stats (vehicles, queue, flow, congestion, speed), alerts, last 2 min timeline. |
| `/ws/video/{id}/push` | Browser camera: client sends JPEG frames (binary); server replies per frame with `{stats, tracks: [{id, cls, conf, stopped, box (fractions)}], proc_fps}`. |
| `/ws/bookings/{id}` | Immediately on connect, then every 0.5 s: `{type: "booking", booking_id, sim_time, sent_at, booking: {id, status, eta_s, ambulance, route, pickup, metrics, failure_reason}, events}` |

Clients may send any text (e.g. `"ping"`) as a keep-alive. If no message arrives for a few seconds, clients show the data as stale and reconnect with back-off; the Flutter app also polls `GET /api/bookings/{id}` while disconnected.
